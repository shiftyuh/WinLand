# AI 余额 · 小岛上看各家 AI 账户余额和今日消耗

把 DeepSeek、魔搭（ModelScope）这些 AI 服务的**账户余额**搬上灵动岛：小岛常驻显示金额，展开看每家一行，
点一下弹出大卡片看余额明细与**今日 / 本周消耗**。余额快见底时自动标红预警。

## 功能

- **小岛**：每家一个「图标 + 余额」，一行放下；低于预警线标红；备注显示「今日 -1.23」。
- **展开**：每家一行（名称 / 金额 / 今日消耗），底部一行更新时间。
- **大卡片（点岛体）**：余额明细（DeepSeek 的赠送 / 充值余额，魔搭的可用 / 预扣）、
  今日消耗 / 本周消耗、接口错误原因、手动刷新按钮。
- **本地采样算消耗**：余额接口都只有当下快照、没有消费明细，插件每次查询成功就记一条余额，
  相邻两条的下降量累加成本日 / 本周消耗（充值不算消耗，跨午夜归新的一天，本周从周一算）。
  只留最近 35 天。
- **多供应商，声明式扩展**：`providers.json` 里一行配置就能接一家新官方供应商
  （接口地址 + JSON 取值路径），不用改代码、不用等插件更新。

## 内置供应商

| 供应商 | 说明 |
|---|---|
| **DeepSeek** | 官方 `GET /user/balance`：总余额 / 赠送 / 充值 + 币种 |
| **魔搭 ModelScope** | 官方「魔粒」余额：总量 / 可用 / 预扣 |

## 怎么用

1. 设置 → 插件 → **AI 余额**，把密钥粘贴进去点「保存」（DeepSeek 用 `sk-` 开头的 API Key，魔搭用 `ms-` 访问令牌），
   点「测试」可立刻验证。
2. 密钥用 **Windows DPAPI（当前用户）** 加密后存在插件自己的目录，明文不进宿主设置、不进日志；
   也可以不填，改在 `providers.json` 里写 `keyEnvVar` 走环境变量。
3. 刷新间隔可在 1 / 5 / 15 / 30 / 60 / 180 分钟里选，默认 5 分钟。

## 权限与数据

- **网络**：只访问 `api.deepseek.com`、`modelscope.cn`（以及你自己在 providers.json 里写的地址）。
- **文件**：插件目录下的 `providers.json`（供应商配置）、`keys.dat`（DPAPI 加密的密钥）、`history.json`（本地采样）。
- **不需要管理员权限**，不写注册表，不改其他插件的数据。

## 要求

- WinIsland ≥ 2.3.0（用到 `IIslandTheme` 与聚光卡 API）。
- 余额接口需要联网；失败时保留上一次的数字，并在大卡片里写明原因（密钥无效 / 无权限 / 限流 / 超时等）。

## 说明

魔搭只有余额快照，没有消费明细端点，所以未提供逐笔账单；签到领魔粒是网页行为，token 体系无法自动签到。
消耗是本地采样推算，宿主关闭期间的消耗会在下次启动时以一次差额补上（数字准，只是没有中间曲线）。
