## 二、还差最后一步：提 PR（需要 GitHub 凭据）

本机**没有 `gh` CLI，也没有任何 GitHub 凭据**（`~/.git-credentials`、`gh` hosts 都不存在），
所以推送/建 PR 这一步没法替你完成。两种做法：

### 方式 A：网页上传（不用装任何工具，最省事）

1. 打开 https://github.com/luolangaga/WinLandPlugin ，点 **Fork**（fork 到你自己的账号）。
2. 在你的 fork 里点 **Add file → Upload files**，把本仓库的 `marketplace/ai-balance/` **整个文件夹**拖进去，
   路径必须落在 `plugins/ai-balance/`（GitHub 网页支持拖文件夹，会保留相对路径；若只上传文件，
   文件名里手动写 `plugins/ai-balance/文件名` 也可以）。
3. Commit 到 fork 的 `main`。
4. 回到上游仓库点 **Compare & pull request**，按下面模板写说明。

### 方式 B：命令行（装了 gh 之后）

```powershell
# 1. 登录（一次性）
gh auth login

# 2. fork + clone
gh repo fork luolangaga/WinLandPlugin --clone
cd WinLandPlugin

# 3. 建分支、放文件
git checkout -b add-plugin-ai-balance
New-Item -ItemType Directory -Force plugins\ai-balance | Out-Null
Copy-Item <本仓库>\marketplace\ai-balance\* plugins\ai-balance\ -Recurse
git add plugins/ai-balance
git commit -m "feat: add ai-balance plugin"

# 4. 推 + 建 PR
git push origin add-plugin-ai-balance
gh pr create --title "Add plugin ai-balance" --body-file <下面的 PR 说明>
```

> 不要手动改 `index.json` 和 `README.md` 里的插件表格 —— 合并后 GitHub Action（`build-index.yml`）
> 会扫描 `plugins/*/plugin.json` 自动生成，包括 sha256、体积和内嵌 logo。

## 三、PR 说明模板

```markdown
## ai-balance · AI 余额

小岛显示各家 AI 服务的账户余额（内置 DeepSeek 官方余额、魔搭魔粒），
并靠本地采样算出今日 / 本周消耗；点岛体弹出大卡片看余额明细与消耗。

### 功能
- 小岛：每家「图标 + 余额」，低于预警线标红，备注显示今日消耗
- 展开：每家一行（名称 / 金额 / 今日消耗）+ 更新时间
- 大卡片：赠送/充值、可用/预扣、今日/本周消耗、错误原因、手动刷新
- 供应商声明式扩展：providers.json 里加一段即可接新官方供应商，不用改代码

### 测试环境
- WinIsland 2.4.0 源码构建（本仓库 main），Windows 10 Pro 25H2 (build 26200)
- 插件已通过市场仓库 tools/build-index.ps1 校验

### 网络与文件
- 网络：只访问 api.deepseek.com 与 modelscope.cn（以及用户在 providers.json 里自行添加的地址）
- 文件：插件目录下的 providers.json / keys.dat（DPAPI 加密的密钥）/ history.json（本地采样）
- 不写注册表、不需要管理员权限、不访问其他插件数据

### 其他
- 许可证 MIT；不需要额外依赖（包内只有自己的 AiBalance.dll）
```

## 四、以后更新版本

1. 改 `plugins-src/AiBalance` 代码，记得把 `plugin.json` 的 `version` 提一版（如 1.0.1）；
2. 重新执行：

   ```powershell
   cd WinLand
   powershell -ExecutionPolicy Bypass -File tools\pack-plugin.ps1 -ProjectDir plugins-src\AiBalance -Configuration Release
   ```

   （`pack-plugin.ps1` 已修成显式 UTF-8 读 plugin.json —— Windows PowerShell 5.1 在无 BOM 时会按 ANSI 解码，中文描述会让 `ConvertFrom-Json` 直接失败。）
3. 把新的 `.lwp` 和 `plugin.json` 覆盖到 `marketplace/ai-balance/`，再提一个 PR。
   CI 会重算 sha256，客户端刷新市场就能看到「可更新」。
